# danielketterer.github.io

Personal portfolio site for Daniel Ketterer. Static HTML/CSS/JS, no build step.

## Deploy (one time)

1. On GitHub, create a new public repository named exactly `DanielKetterer.github.io`.
2. Upload every file in this folder to the repository root on the `main` branch
   (Add file > Upload files works fine; no git required).
3. Wait a minute or two. The site goes live at https://danielketterer.github.io
   automatically - repositories named `<username>.github.io` are served by
   GitHub Pages without any settings changes.

## Updating

- Edit `index.html` for content, `main.css` for styling, `script.js` for behavior.
- Replace `undergraduate_thesis.pdf` with the real thesis, keeping the filename,
  and the existing link will work.
- `resume.pdf` and `toward_f.pdf` can be swapped the same way when new versions exist.

## Files

- `index.html` - the page
- `demo.html` - interactive mutualism / identification-problem simulation
- `mutualism_figure.png` - hero figure
- `main.css` - styles
- `script.js` - mobile nav, scroll reveals, active-section highlight
- `portrait.jpg` - headshot (800x1120, web-optimized)
- `resume.pdf` - technologist resume
- `toward_f.pdf` - "Toward f: A General Factor of Human Flourishing"
- `undergraduate_thesis.pdf` - placeholder, replace with the real file
